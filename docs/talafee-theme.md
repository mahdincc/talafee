# Talafee Theme

A modern minimal theme with subtle gold accents, designed for financial data clarity and bilingual (Persian/English) support.

## Color Palette

- **Pure White**: `#FFFFFF` - Cards, surfaces
- **Snow**: `#FAFAFA` - Page background
- **Graphite**: `#1A1A1A` - Primary text, headlines
- **Slate**: `#6B7280` - Secondary text
- **Silver**: `#E5E7EB` - Borders, dividers
- **Gold**: `#D4AF37` - Primary accent, brand color
- **Gold Light**: `#FDF8E8` - Subtle gold backgrounds
- **Emerald**: `#10B981` - Price up, positive
- **Ruby**: `#EF4444` - Price down, negative

## Typography

- **Headers**: Outfit Bold
- **Body Text**: Work Sans Regular
- **Prices & Numbers**: Geist Mono
- **Persian Fallback**: Vazirmatn

## Best Used For

Financial dashboards, price comparison tools, trading applications, bilingual Persian/English interfaces, gold and commodity tracking.

## Design Characteristics

- Clean whitespace with data-forward layouts
- Subtle elevation through shadows, not borders
- Gold accent sparingly used for emphasis
- Monospace numbers for price alignment
- Full RTL support for Persian content
